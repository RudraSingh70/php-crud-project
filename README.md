# PHP CRUD Project

A simple CRUD (Create, Read, Update, Delete) web application developed using **PHP**, **MySQL**, **HTML**, and **CSS**. This project demonstrates database connectivity, form handling, and complete CRUD operations.

## Features

- Create new records
- View all records
- Update existing records
- Delete records
- MySQL database integration
- Simple and responsive interface

## Tech Stack

- PHP
- MySQL
- HTML5
- CSS3
- XAMPP
- Git & GitHub

## Installation

1. Clone the repository

```bash
git clone https://github.com/RudraSingh70/php-crud-project.git
```

2. Start **Apache** and **MySQL** in XAMPP.

3. Copy the project into

```
C:\xampp\htdocs\
```

4. Create a database named

```
trip
```

5. Import

```
database/trip.sql
```

6. Open

```
http://localhost/php-crud-project/
```
